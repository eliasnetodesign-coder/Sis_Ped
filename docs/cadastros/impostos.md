# Impostos

`admin/cadastros/impostos.php` — acesso `comercial`, `supervisor` ou `tecnologia da informacao`.

Cadastro das empresas do grupo (ex.: **Network**, **Accademia**) para fins de apuração de impostos. Permite cadastrar quantas empresas forem necessárias.

## Campos

- **Nome*** (`impostos_empresas.nome`)
- **CNPJ*** (`impostos_empresas.cnpj`)
- **IRPJ %** (`impostos_empresas.irpj`)
- **CSLL %** (`impostos_empresas.csll`)
- **ISS %** (`impostos_empresas.iss`)
